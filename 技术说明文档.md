# 个人健康管理系统 - 技术说明文档

## 1. 项目概述

本项目是一个**个人健康管理系统**，旨在为用户提供全面的健康数据管理、健康资讯浏览、食谱推荐等功能。系统采用前后端分离架构，支持管理员和普通用户两种角色。

### 1.1 项目定位

- **目标用户**：普通用户和系统管理员
- **核心价值**：帮助用户记录和管理个人健康数据，获取健康资讯，制定合理饮食计划

### 1.2 主要功能

| 功能模块 | 功能描述 | 用户角色 |
| :--- | :--- | :--- |
| 用户管理 | 用户注册、登录、信息管理、密码修改 | 管理员/普通用户 |
| 健康资讯 | 资讯浏览、详情查看、评论互动 | 普通用户 |
| 健康模组 | 健康指标配置、数据统计展示 | 管理员/普通用户 |
| 健康记录 | 健康数据录入、查看、统计分析 | 普通用户 |
| 食谱管理 | 食谱发布、审核、浏览、收藏 | 管理员/普通用户 |
| 评论管理 | 评论查看、审核、删除 | 管理员 |
| 饮食记录 | 饮食数据录入、统计分析 | 普通用户 |
| 收藏夹 | 食谱、资讯收藏管理 | 普通用户 |

#### 2.3.5 安全设计

**JWT认证流程**：

```
用户登录 → 验证用户名密码 → 生成JWT Token → 返回Token
    ↓
后续请求 → 请求头携带Token → JWT拦截器验证 → 业务处理 → 返回结果
```

**Token结构**：
- Header: `{ "alg": "HS256", "typ": "JWT" }`
- Payload: `{ "userId": 1, "role": 2, "exp": 过期时间 }`
- Signature: HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), secret)

## 3. 功能模块详细技术实现

### 3.1 用户认证与权限管理

#### 3.1.1 JWT认证机制实现

系统采用JWT（JSON Web Token）实现无状态身份认证，核心通过`JwtInterceptor`拦截器实现。

**JwtInterceptor核心逻辑**：

```java
// JwtInterceptor.preHandle() 实现
@Override
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws Exception {
    // 1. 放行OPTIONS预检请求
    if ("OPTIONS".equals(request.getMethod())) {
        return true;
    }

    // 2. 定义无需认证的路径白名单
    String[] excludePaths = {"/login", "/register", "/file"};

    // 3. 检查请求路径是否在白名单中
    for (String path : excludePaths) {
        if (requestURI.contains(path)) {
            return true;
        }
    }

    // 4. 从请求头提取Token
    String authHeader = request.getHeader("Authorization");
    if (authHeader == null || !authHeader.startsWith("Bearer ")) {
        return sendError(response, "认证头格式错误：应为 'Bearer <token>'");
    }

    // 5. 验证Token并获取用户信息
    Claims claims = JwtUtil.fromToken(token);
    Integer userId = claims.get("id", Integer.class);
    Integer roleId = claims.get("role", Integer.class);

    // 6. 存储到线程局部变量供后续使用
    LocalThreadHolder.setUserId(userId, roleId);

    return true;
}
```

**Token生成与验证工具类**：

| 方法 | 功能说明 | 参数 |
| :--- | :--- | :--- |
| `JwtUtil.generateToken(user)` | 生成Token | 用户实体对象 |
| `JwtUtil.fromToken(token)` | 解析Token | Token字符串 |
| `JwtUtil.verifyToken(token)` | 验证Token | Token字符串 |

#### 3.1.2 用户登录实现

**登录流程**：

```
用户输入账号密码 → 前端MD5加密密码 → POST请求 /user/login
    ↓
后端验证账号密码 → 生成JWT Token → 返回Token和用户信息
    ↓
前端存储Token到LocalStorage → 跳转到对应角色首页
```

**前端登录请求封装**：

```javascript
// utils/request.js 中的请求拦截器
request.interceptors.request.use(config => {
    const token = getToken();
    if (token) {
        config.headers.Authorization = `Bearer ${token}`
    }
    return config;
});

// views/login/Login.vue
async handleLogin() {
    const { data } = await this.$axios.post('/user/login', {
        account: this.loginForm.account,
        password: this.$md5(this.loginForm.password) // MD5加密
    });
    setToken(data.token);
    setRole(data.role);
    this.$router.push(data.role === 1 ? '/admin-layout' : '/home');
}
```

#### 3.1.3 前端路由权限控制

**路由守卫实现**：

```javascript
// router/index.js
router.beforeEach((to, from, next) => {
    // 1. 放行登录和注册页面
    if (to.path === '/login' || to.path === '/register') {
        return next();
    }

    // 2. 检查需要认证的路由
    if (to.matched.some(record => record.meta.requireAuth)) {
        const token = getToken();

        // 3. 未登录则跳转到登录页
        if (!token) {
            return next({ path: '/login', query: { redirect: to.fullPath } });
        }

        // 4. 角色权限校验
        const role = parseInt(getRole());
        if (to.matched[0].path === '/admin' && role !== 1) {
            clearToken();
            return next("/login");
        }
        if (to.matched[0].path === '/user' && role !== 2) {
            clearToken();
            return next("/login");
        }
    }
    next();
});
```

**BMI计算逻辑**：

```java
public BMIResultVO computeBMI(BMIDto bmiDto) {
    double height = bmiDto.getHeight() / 100.0; // 转换为米
    double weight = bmiDto.getWeight();
    double bmi = weight / (height * height);

    String info;
    if (bmi < 18.5) {
        info = "偏瘦";
    } else if (bmi < 24) {
        info = "正常";
    } else if (bmi < 28) {
        info = "偏胖";
    } else {
        info = "肥胖";
    }

    return BMIResultVO.builder()
        .result(String.format("%.1f", bmi))
        .info(info)
        .build();
}
```

**BMI判断标准**：

| BMI范围 | 分类 | 建议 |
| :--- | :--- | :--- |
| < 18.5 | 偏瘦 | 增加营养摄入 |
| 18.5 - 24 | 正常 | 保持健康生活方式 |
| 24 - 28 | 偏胖 | 控制饮食，加强运动 |
| >= 28 | 肥胖 | 建议咨询医生 |

```java
public Result<Object> upvoteOperation(Evaluations evaluations) {
    Integer userId = LocalThreadHolder.getUserId();
    // 1. 查询用户是否已点赞
    EvaluationsUpvote upvote = evaluationsUpvoteMapper.selectByUserAndEvaluations(
        userId, evaluations.getId());

    if (upvote == null) {
        // 2. 未点赞则添加点赞记录
        evaluationsUpvoteMapper.insert(buildUpvote(userId, evaluations.getId()));
        evaluations.setUpvoteCount(evaluations.getUpvoteCount() + 1);
    } else {
        // 3. 已点赞则取消点赞
        evaluationsUpvoteMapper.deleteById(upvote.getId());
        evaluations.setUpvoteCount(evaluations.getUpvoteCount() - 1);
    }

    // 4. 更新评论点赞数
    evaluationsMapper.updateById(evaluations);
    return Result.success();
}
```

### 3.9 分页功能实现

#### 3.9.1 分页注解与切面

**分页注解**（`Pager.java`）：

```java

```

**分页切面**（`PagerAspect.java`）：

```java
@Aspect
@Component
public class PagerAspect {

    @Around("@annotation(pager)")
    public Object handlePageableParams(ProceedingJoinPoint joinPoint, Pager pager) throws Throwable {
        Object[] args = joinPoint.getArgs();
        for (Object arg : args) {
            if (arg instanceof QueryDto) {
                QueryDto queryDTO = (QueryDto) arg;
                configPager(queryDTO);
            }
        }
        return joinPoint.proceed(args);
    }

    // 分页参数转换：前端传入current页码，转为MySQL的offset
    private void configPager(QueryDto queryDTO) {
        if (queryDTO.getCurrent() != null && queryDTO.getSize() != null) {
            queryDTO.setCurrent((queryDTO.getCurrent() - 1) * queryDTO.getSize());
        }
    }
}
```

```java
public Result<String> uploadFile(MultipartFile file) {
    // 1. 验证文件类型
    String originalFilename = file.getOriginalFilename();
    String ext = originalFilename.substring(originalFilename.lastIndexOf("."));

    // 2. 生成唯一文件名
    String filename = UUID.randomUUID().toString().replace("-", "") + ext;

    // 3. 构建存储路径
    String dirPath = "upload/" + DateUtil.formatDate(new Date(), "yyyy-MM-dd");
    File dir = new File(dirPath);
    if (!dir.exists()) {
        dir.mkdirs();
    }

    // 4. 保存文件
    File targetFile = new File(dirPath, filename);
    file.transferTo(targetFile);

    // 5. 返回访问路径
    String fileUrl = "/file/" + filename;
    return Result.success(fileUrl);
}
```

## 5. 代码安全性

### 5.1 注意事项

| 风险类型 | 风险描述 | 关联模块 |
| :--- | :--- | :--- |
| SQL注入 | 用户输入未经验证直接拼接SQL | Mapper层、Service层 |
| XSS攻击 | 用户输入包含恶意脚本 | 评论模块、资讯内容 |
| CSRF攻击 | 跨站请求伪造 | 所有POST接口 |
| 敏感信息泄露 | 密码明文存储、日志打印敏感信息 | 用户模块 |
| 文件上传漏洞 | 恶意文件上传 | 文件上传接口 |
| JWT安全 | Token过期处理、密钥泄露 | 认证模块 |

### 5.2 解决方案

| 风险类型 | 解决方案 | 实施位置 |
| :--- | :--- | :--- |
| SQL注入 | 使用MyBatis Plus参数化查询，禁止字符串拼接 | Mapper层 |
| XSS攻击 | 使用富文本编辑器过滤，输出时进行HTML转义 | 前端表单、后端存储 |
| CSRF攻击 | 使用JWT Token认证，无状态请求 | 全局拦截器 |
| 敏感信息泄露 | 密码使用MD5加密存储，日志脱敏处理 | UserService |
| 文件上传漏洞 | 限制文件类型、大小，存储路径随机化 | FileController |
| JWT安全 | 设置合理过期时间，使用安全的密钥管理 | JwtInterceptor |
