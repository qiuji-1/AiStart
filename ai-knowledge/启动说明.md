# 启动说明

## 启动服务器

```bash
cd a:\Workspace\AiStart\ai-knowledge
node server.js
```

启动后会显示：
```
🚀 服务器已启动
📍 访问地址: http://localhost:3000
📁 数据文件: a:\Workspace\AiStart\ai-knowledge\user-data.json
```

## 访问网页

打开浏览器访问 **http://localhost:3000**

## 数据存储

| 数据类型 | 存储位置 |
|---------|---------|
| LocalStorage | 浏览器内存（换浏览器会丢失） |
| user-data.json | 本地文件（永久保存） |

## 工作流程

1. 每次保存数据时，会同时写入 `user-data.json`
2. 每次打开网页时，会从 `user-data.json` 加载数据到 LocalStorage
3. 换电脑时，只需复制 `user-data.json` 并覆盖即可恢复数据

## 停止服务器

按 `Ctrl+C` 停止
