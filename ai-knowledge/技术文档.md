# AI编程知识体系网站 - 技术文档

## 一、项目概述

本项目是一个纯前端实现的AI编程知识体系学习网站，集成了思维导图、导航系统、搜索功能、进度追踪和笔记管理等功能。

### 1.1 技术栈

| 类型 | 技术 |
|------|------|
| 前端框架 | 原生 HTML5 + CSS3 + JavaScript (ES6+) |
| 后端 | Node.js (Express.js) |
| 数据存储 | LocalStorage + JSON文件 |
| 图表渲染 | D3.js (思维导图) |
| Markdown解析 | marked.js |

### 1.2 核心特性

- **交互式思维导图**：中心辐射式知识地图，支持拖拽、缩放
- **多级导航系统**：12个知识章节，支持展开/折叠
- **实时搜索**：关键词高亮，快速定位
- **学习进度追踪**：LocalStorage持久化
- **每日打卡**：日历视图+目标管理
- **Markdown笔记**：内置编辑器支持Markdown语法
- **三种视图模式**：只读/编辑/分栏对比

## 三、核心模块详解

### 3.1 app.js - 主应用

负责整体页面初始化和模块协调。

**主要功能**：
- `initApp()` - 初始化所有模块
- `loadData()` - 加载知识数据
- `renderView()` - 渲染当前视图

```javascript
// 初始化流程
initApp() → loadData() → renderNavigation() → renderMindmap()
```

### 3.2 mindmap.js - 思维导图

基于D3.js实现的交互式知识地图。

**核心类**：`MindMap`

**主要方法**：
| 方法 | 功能 |
|------|------|
| `constructor(svgElement)` | 构造函数，初始化D3绑定 |
| `loadData(data)` | 加载数据并渲染 |
| `centerOnNode(nodeId)` | 以节点为中心聚焦 |
| `highlightPath(nodeId)` | 高亮路径 |
| `expandNode(nodeId)` | 展开节点 |
| `collapseNode(nodeId)` | 折叠节点 |

**数据结构**：
```javascript
{
  id: "ai-fundamentals",
  name: "AI基础",
  children: [
    { id: "ml-basics", name: "机器学习基础", children: [...] }
  ]
}
```

### 3.3 navigation.js - 导航系统

左侧导航树，支持12个知识章节。

**核心类**：`Navigation`

**主要方法**：
| 方法 | 功能 |
|------|------|
| `init()` | 初始化导航 |
| `expandChapter(chapterId)` | 展开章节 |
| `collapseChapter(chapterId)` | 折叠章节 |
| `highlightItem(itemId)` | 高亮导航项 |
| `syncWithMindmap(nodeId)` | 与思维导图同步 |

### 3.4 search.js - 搜索功能

实时搜索+结果高亮。

**核心类**：`Search`

**主要方法**：
| 方法 | 功能 |
|------|------|
| `init(inputElement)` | 初始化搜索框 |
| `search(query)` | 执行搜索 |
| `highlightResults(results)` | 高亮显示结果 |
| `clearHighlight()` | 清除高亮 |

**搜索算法**：
1. 遍历所有节点，匹配name和description字段
2. 支持模糊匹配
3. 返回匹配结果及其路径

### 3.5 progress.js - 进度追踪

记录用户学习进度。

**核心类**：`ProgressTracker`

**主要方法**：
| 方法 | 功能 |
|------|------|
| `markComplete(nodeId)` | 标记完成 |
| `markInProgress(nodeId)` | 标记进行中 |
| `getProgress()` | 获取进度统计 |
| `saveToStorage()` | 保存到LocalStorage |
| `loadFromStorage()` | 从LocalStorage加载 |

**存储格式**：
```javascript
{
  completed: ["node-id-1", "node-id-2"],
  inProgress: ["node-id-3"],
  lastUpdated: "2026-04-16"
}
```

### 3.6 checklist.js - 打卡功能

每日学习打卡系统。

**核心类**：`Checklist`

**主要方法**：
| 方法 | 功能 |
|------|------|
| `checkIn(date)` | 执行打卡 |
| `getCalendar()` | 获取打卡日历 |
| `setGoal(goal)` | 设置每日目标 |
| `getStreak()` | 计算连续打卡天数 |

**打卡数据结构**：
```javascript
{
  checkins: [
    { date: "2026-04-16", completed: true, note: "学习策略模式" }
  ],
  goals: {
    daily: 3,  // 每日目标（章节数）
    streak: 5  // 当前连续天数
  }
}
```

## 四、API接口

### 4.1 后端服务 (server.js)

**服务器配置**：
```javascript
const PORT = 3000;
const DATA_FILE = './user-data.json';
```

**API端点**：

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/data` | 获取用户数据 |
| POST | `/api/progress` | 更新学习进度 |
| POST | `/api/checkin` | 提交打卡 |
| GET | `/api/calendar` | 获取打卡日历 |
| PUT | `/api/goals` | 更新目标设置 |

**请求/响应示例**：

```javascript
// GET /api/progress
Response: {
  completed: ["ai-fundamentals", "ml-basics"],
  inProgress: ["dl-intro"],
  totalNodes: 156,
  completionRate: 0.12
}

// POST /api/checkin
Request: { date: "2026-04-16", note: "完成策略模式学习" }
Response: { success: true, streak: 3 }
```

### 4.2 前端存储API

**LocalStorage Keys**：

| Key | 内容 |
|-----|------|
| `ai_progress` | 学习进度数据 |
| `ai_checkins` | 打卡记录 |
| `ai_goals` | 目标设置 |
| `ai_notes` | 用户笔记 |
| `ai_preferences` | 用户偏好 |

## 五、数据结构

### 5.1 知识树节点

```javascript
{
  id: String,           // 唯一标识
  name: String,         // 节点名称
  description: String,  // 节点描述
  children: Array,      // 子节点
  metadata: {
    difficulty: "beginner|intermediate|advanced",
    estimatedTime: Number,  // 预计分钟数
    prerequisites: Array,   // 前置知识ID
    tags: Array            // 标签
  }
}
```

## 九、扩展指南

### 9.1 添加新章节

在 `js/data.js` 中添加节点数据：

```javascript
{
  id: "new-chapter",
  name: "新章节",
  children: [
    { id: "topic-1", name: "主题1" }
  ]
}
```

### 9.2 自定义主题

修改 `css/style.css` 中的CSS变量即可更换主题色。

### 9.3 添加新功能

建议在 `js/` 目录下创建独立模块文件，参考现有模块的结构，然后在 `app.js` 中引入。
